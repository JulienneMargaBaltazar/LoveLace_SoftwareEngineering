# Module Sprint Map
This plan maps six software modules to four sprints to launch the new ERP system in 8 weeks.
## Module Mapping Table

| Module ID | Module Title | Primary Sprint | Active Target Weeks | Key System Deliverables |
| :--- | :--- | :---: | :---: | :--- |
| MOD-1 | System Scaffolding & Identity Foundation | Sprint 1 | Weeks 1 - 2 | Core frameworks, authentication infrastructure, and security-controlled User Management screen panels. |
| MOD-2 | Customer Relationship Management (CRM) | Sprint 2 | Weeks 3 - 4 | Customer directory grids, full text index lookups, data validation constraints, and secure soft-delete toggles. |
| MOD-3 | Product Lifecycle & Dynamic Pricing Engine | Sprint 2 | Weeks 3 - 4 | Product profiles, effective-date timeline price logs, pricing lookup functions, and inventory search tuning. |
| MOD-4 | Human Resources (HR) Matrix | Sprint 3 | Weeks 5 - 6 | Department/job CRUD structures, user account tracking bindings, job histories, and wage field redactions. |
| MOD-5 | Transactional Sales Ledger | Sprint 4 | Weeks 7 - 8 | Invoicing, automated index sequencing numbers, multi-product line sub-ledgers, and customer balance tracking columns. |
| MOD-6 | Enterprise Analytics & Reporting Engine | Sprint 4 | Weeks 7 - 8 | 7 parameter-filtered business reports, print-to-PDF generation drivers, and a superadmin safety audit trail viewer. |



## Sprint Execution Plan


### Sprint 1 (Weeks 1 - 2)
* **Active Module:** Module 1: System Scaffolding & Identity Foundation
* **Core Deliverables:** 
  * Full base application skeleton repository with centralized environment configuration variables.
  * Secure server-side user database connections utilizing query script runners.
  * Encrypted authentication gateways handling session state parameters, logout procedures, and one-time password initialization mechanics.
  * User Directory interfaces enabling administrative staff to search, update, approve, block, or unblock user accounts.
  * Fine-grained role matrix dialog dashboard tracking individual permission privileges across 36 core system actions.
  * UI system documentation including colors, components, structural layouts, and hi-fi design wireframe packages.

### Sprint 2 (Weeks 3 - 4)
* **Active Modules:** Module 2: Customer Relationship Management & Module 3: Product Lifecycle & Dynamic Pricing Engine
* **Core Deliverables:**
  * Searchable Customer and Product interface lists optimized with active view queries and database indexes.
  * Data entry validation fields enforcing structural formats across fields like payment terms and unit counts.
  * Safe destructive logic models executing data soft deletes with companion restoration tracking fields.
  * Relational parent safety blocks preventing parent profile destruction when active child record dependencies are found.
  * Pricing history lookup functions computing accurate product pricing matrix states as of any past or future effective date parameters.
  * UX component design views representing error states, empty dashboards, and user confirmation modals.

### Sprint 3 (Weeks 5 - 6)
* **Active Module:** Module 4: Human Resources (HR) Matrix
* **Core Deliverables:**
  * Relational catalog management interfaces for organizational Departments and Job level categories.
  * Employee data profile management grids storing deployment assignments, personal details, and separation dates.
  * Automated unique database keys linking logical system application user credentials to physical corporate employee records.
  * Personnel movement timelines managing promotion history logs, historical context fields, and effective dates.
  * Security field-level masking blocks dynamically hidden based on explicit permission configurations to obscure sensitive employee salary data.
  * Experience layout design structures modeling comprehensive organizational job history timelines.

### Sprint 4 (Weeks 7 - 8)
* **Active Modules:** Module 5: Transactional Sales Ledger & Module 6: Enterprise Analytics & Reporting Engine
* **Core Deliverables:**
  * Sales transaction invoice headers powered by unique automated sequence numbers and dropdown selection linkages.
  * Transaction item lists managing unit totals, purchase quantities, and dynamic unit cost lookups pulling historical price metrics matching transaction date timestamps.
  * Accounts ledger system logging partial or complete payments to update net balance parameters.
  * Report generation interface compiling data blocks into the 7 primary functional enterprise operational matrices.
  * Native print-to-PDF drivers generating document downloads equipped with date-range filters and top-N optimization parameters.
  * Centralized security logs capturing application footprint histories for exclusive superadmin review dashboard views.
  * Final production integration package tracking extensive holistic system regression cycles and launch scripts.
